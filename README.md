A one-line roast of a smart fridge: it nags about the door but stays silent about the leftovers growing a civilization in the crisper drawer.

## The entry

> My smart fridge beeps when the door stays open but stays silent about the leftovers growing a civilization in the crisper drawer.

129 characters, one line. The joke turns the fridge into a silent accomplice: it beeps at an open door yet says nothing about the leftovers rotting into a civilization. It dodges the stock jokes flooding the field (ordering too much milk, 3 AM snacks, the door alarm as the punchline).

## Run it

```sh
node main.ts
```

`main.ts` validates the line (single line, 1–160 characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline so the file is exactly the one line.
